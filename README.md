# 📊 Indian Mutual Fund Analytics Dashboard | Power BI

An end-to-end **Business Intelligence (BI)** solution built using **Power BI, SQL, DAX, and Power Query** to analyze India's mutual fund ecosystem. This dashboard transforms raw financial datasets into interactive insights, enabling stakeholders to monitor fund performance, investor behavior, AUM trends, SIP inflows, and redemption patterns for data-driven investment decisions.

---

## 📌 Project Overview

The **Indian Mutual Fund Analytics Dashboard** is designed to provide a comprehensive view of mutual fund performance across multiple fund houses. By integrating data from various financial sources, the dashboard delivers actionable insights through interactive visualizations, KPI monitoring, and trend analysis.

The project demonstrates the complete BI workflow, including:

- Data Collection
- Data Cleaning & Transformation
- Data Modeling
- DAX Calculations
- Interactive Dashboard Design
- Business Insights & Reporting

---

# 🚀 Business Problem

Financial institutions and investors often struggle to analyze large volumes of mutual fund data spread across multiple sources.

Key challenges include:

- Monitoring Assets Under Management (AUM)
- Tracking Net Asset Value (NAV)
- Comparing Fund House Performance
- Measuring SIP Growth
- Identifying Investor Trends
- Monitoring Redemption Amounts
- Understanding Year-over-Year Growth

This dashboard provides a centralized reporting solution that enables faster and more informed investment decisions.
